## ✅ What Works Today

### Frontend (`apps/web/`)
- TanStack Start (Vite + React 19) running on `pnpm web` → http://localhost:8080
- Tailwind v4 + shadcn/ui design system
- Full Arabic RTL with Egyptian colloquial dialect
- **Home page** (`/`): hero, search bar (UI only), filter chips (UI only), grid of 6 hardcoded properties
- **Property detail page** (`/property/$id`): gallery, trust section, quality scores, amenities, bed-occupancy grid, reviews, Q&A, sticky pricing sidebar with cost breakdown
- Trust UI components: `TrustBadge`, `ScoreBar`
- Site chrome: `SiteHeader`, `SiteFooter` (Egyptian Arabic)
- Routes auto-generated by TanStack Router plugin

### Backend (`apps/api/`)
- NestJS 11 scaffolded
- Prisma + Postgres + PostGIS configured in `docker-compose.yml`
- Redis + Meilisearch declared but flaky in dev (Redis connection errors)
- **Not connected to frontend yet**

### Monorepo
- Turborepo + pnpm workspace
- Root scripts: `pnpm web`, `pnpm api`, `pnpm dev` (all)
- `.github/copilot-instructions.md` and `.cursorrules` present
